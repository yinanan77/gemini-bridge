# 本次修订诊断（主控给执行者的必要背景）

## 用户原始目标
从黑桃9、思远的视频文稿归纳一套可照写的男士发型改造文稿框架（开头/中段/结尾→段内步骤→句间衔接→句式），先照成熟写法仿写，再创新。只做文稿，不做分镜/剪辑。框架最终要入库并用于实际写稿，目前候选阶段、未获用户认可、未写入数据库。

## 用户已明确否定
1. 开场不能只定义为“让观众等答案”，必须有真实吸引点（钩子）；也不要只说“有钩子”，要写清凭什么吸引。
2. 乖巧男生旧稿流量低，不能当正向示范。
3. 现演练稿（TRIAL-baseline）开头拖拉、理解成本高；“想让人先注意到他，光换件衣服还不够”是无效加戏，应直接删且不要换成别的一句过渡。
4. 方案收束（“有自己的想法…愿意听她说”）位置对但平淡。
5. 结尾整段意思没问题，只是太长；应保留意思并压缩，不是换掉。

## 上一轮的真实病灶（必须纠正）
为修“开头拖拉”，现稿把豹纹原作的审美主线换成了另一套人物故事：
- 现稿：她约他逛街 → 他答“你挑，我拎” → 做完头发 → 进店自己绕一圈拿衣 → 她问哪件，他指左边。
- 结果：故事变成“从被动、没主见，到会主动挑衣服”，与“浅金、碎发、豹纹让外形更有锋芒”没有因果关系；结尾变成交代新故事，不再兑现原作的“外形难管、相处却有耐心”的反差。
- 结论：这不是优化，是偏题。修短可以，换主题不行。

## 本篇（豹纹）原作必须保留的审美主线
1. 和这类女生一起出门，两个人外形气场要在一个画风里，否则像长辈带孩子；
2. 他黑发+细框眼镜偏收敛，头发顺两边落、刘海和镜框挤在同一位置；
3. 所以重心上移、颜色和轮廓更张扬（浅金、弯曲碎发、露中间额头）；
4. 预告：看起来不太好安排，但一招手又会自己走过去；
5. 成品：背心露肩臂、豹纹接住张扬、发尾散开、金属的硬配头发软；
6. 落点：看起来难管，但愿意陪她多逛两家店。

允许为了短、清楚而重写表达，不允许把“张扬/难管/耐心”换成“有没有主见/会不会挑衣服”。

## 硬边界
- 造型事实只能用原作给的：黑发、细框眼镜、两侧下落、刘海与镜框同位、重心上移、浅金、弯曲碎发、中间露额、边缘散开的发尾、白背心、豹纹、金属。不得新增脸型、发质、烫染流程、发量、动态（如“走起来会晃”）、配饰类别、效果承诺。
- 虚构场景必须标为设定，不能写成顾客原话或真实履历。
- 不得把发型效果写成真实性格改变或行为改变。
- 原文引句可去时间码、合并断行，不得改写后又称为原话。
- 不写分镜、时间码、补拍清单。
- 不声称任何流量、完播、获客效果；文本合规不等于好看。

## 三份交付的原有信息程度（不得缩成提纲）
- FRAMEWORK：三条开场路径、钩子与理解成本、黑桃默认四步、思远方向后置与灰裤多轮分支、句式骨架与自拟/原文区分、结尾不同收法、调用方式、三种结论（原文可见/本轮归纳/未验证效果）。
- MOTHER：18 个单元，每格原句、槽位、承上启下逐字保留，可补分量说明。
- TRIAL：完整连续演练 + 与原作顺序对照 + 修改说明 + 事实/虚构/未验证声明。
